# Iris Dataset Analysis & Classification with Python

## Project Overview
This repository contains a Python-based data analysis and machine learning workflow using the classic **Iris Dataset**. The project explores feature relationships (sepal and petal dimensions) across three species of Iris flowers (*Iris setosa*, *Iris virginica*, and *Iris versicolor*) and builds classification models to accurately predict the species based on visual measurements.
